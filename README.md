# Mybalan S — Portfolio

A responsive portfolio built with HTML, CSS, JavaScript, and lightweight SVG artwork. It is ready to publish with GitHub Pages.

## Preview

Open `index.html` in a browser. The **Edit my details** form can personalize the page in that browser, but those edits are stored only on that device. The current profile details are also written into the site files so they appear to public visitors after publishing.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository named `mybala12.github.io`.
2. Open the repository and choose **Add file → Upload files**.
3. Upload the contents of this folder to the repository’s top level: `index.html`, `styles.css`, `theme.css`, `script.js`, and the complete `assets` folder. Keep the `assets` folder intact so the profile photo and three project illustrations load correctly.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
6. After GitHub finishes publishing, visit `https://mybala12.github.io` and share that address. The first deployment may take a few minutes.

## Resume

The in-page resume upload is saved only in the browser where it was selected. To make a resume available to visitors, add the PDF to this folder at `assets/resume.pdf` before uploading it to GitHub. Later file changes can be committed to the same repository; GitHub Pages republishes them automatically.
